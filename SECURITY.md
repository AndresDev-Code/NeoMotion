# Security Policy

## Supported Versions

Actualmente, la versión estable de NeoMotion es `v1.0.0`.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ |
| < 1.0   | ❌ |

## Reporting a Vulnerability

Si encuentras una vulnerabilidad de seguridad en NeoMotion, por favor evita publicar los detalles de forma pública.

Puedes comunicarte con el mantenedor del proyecto a través de GitHub proporcionando la siguiente información:

- Descripción de la vulnerabilidad.
- Pasos necesarios para reproducirla.
- Archivos o componentes afectados.
- Impacto potencial.

Las vulnerabilidades reportadas serán revisadas y, cuando sea necesario, se publicará una corrección o actualización del proyecto.

Gracias por ayudar a mantener NeoMotion seguro.
